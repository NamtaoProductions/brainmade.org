# Validated Projects

**These are projects that the brainmade community believes are using the mark in the spirit it was designed for.**

If you would like to see your project here, [submit it for review here](https://github.com/NamtaoProductions/brainmade.org/blob/main/CONTRIBUTING.md). If you believe a project is misusing AI tools in a way that is against the spirit of the Brainmade mark, [open a PR deleting the file in the validated directory](https://github.com/NamtaoProductions/brainmade.org/tree/main/content/validated). In both cases, provide explainations and evidence so that the community can confirm.
